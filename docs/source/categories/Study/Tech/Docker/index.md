## Docker简介
### 是什么
如何确保环境能够运行-给出的一套标准化的解决方法---<span style="color: red;">系统平滑移植，容器虚拟化</span>

把源码+配置+环境+版本打包成一个镜像，例如ISO这种镜像文件，搬家总会丢点东西，现在直接把你楼给搬过来
一次镜像处处运行

（一句话）解决了<span style="color: red;">运行环境和配置问题</span>的<span style="color: red;">软件容器</span>，方便做持续集成并有助于整体发布的容器虚拟化技术

### 容器与虚拟机的比较
容器虚拟化解决传统虚拟化的痛点
<span style="color: red;">Linux容器不是模拟一个完整的操作系统</span>
