# huai_code about mahjong
你当前的单文件 HTML 本质是一个纯前端单页应用，所有逻辑耦合在一个文件中，按职责可以拆分为「视图层、样式层、逻辑层」三大块，其中逻辑层又可细分为 12 个独立功能模块。

区块	核心元素	作用
成员管理区	添加输入框、删除下拉框	玩家名单增删
场地选择区	水印城 / 揽云锦绣单选	区分场次，对应导出文件名
实时统计面板	18 项数据指标横向列表	放炮、获胜、自摸、胡数分段等核心数据
胡牌统计面板	放炮 / 自摸牌排行、个人明细、牌局参与	牌面维度的数据统计
输赢榜面板	历史结算记录、财神高亮	历史输赢复盘
玩家选择区	动态渲染的玩家单选按钮组	指定当前操作人
核心操作区	胡 / 截胡 / 泥鳅 / 狗运 / 菜 P/OB/ 结算	主要记账入口
操作日志区	滚动文本框	所有操作流水记录
功能按钮区	撤销 / 清空 / 导出 / 称号 / 军师	辅助功能
弹窗组件（7 个）	极速胡牌、菜 P、狗运、结算、称号、军师、通用选人	所有复杂交互的弹窗载体

按模块归类的样式体系：
基础样式：全局重置、body 背景、字体
组件样式：按钮、弹窗、单选组、统计卡片、日志框
业务专属样式：财神高亮、称号特效、选牌按钮、胡数网格
状态样式：选中态、激活态、禁用态、排行名次配色


mahjong/

├── css/
│   └── style.css           # 所有样式集中管理

    ├── state.js            # 全局状态管理

    ├── utils.js            # 工具函数
    ├── render.js           # UI渲染层
    ├── modules/
    │   ├── userManage.js   # 用户管理
    │   ├── fastHu.js       # 极速胡牌核心逻辑
    │   ├── actions.js      # 单动作操作（截胡/OB/菜P等）
    │   ├── settle.js       # 输赢结算
    │   ├── title.js        # 称号鉴定
    │   ├── military.js     # 军师系统
    │   ├── export.js       # Excel导出
    │   └── keyboard.js     # 【新增】键盘快捷键模块
